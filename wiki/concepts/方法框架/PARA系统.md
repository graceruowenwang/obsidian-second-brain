# PARA系统

PARA 是 Tiago Forte 提出的数字信息组织系统，按照**可行动性**递减的顺序将所有信息分为四个类别：Projects（项目）、Areas（领域）、Resources（资源）、Archives（归档）。

## 核心理念

PARA 的排序不是随意的，它反映了从**行动到参考**的递进关系：
- **项目和领域**是你当前关注的（需要投入精力）
- **资源和归档**是为未来准备的（可能有用但不紧急）

> [原创] PARA 的排序反映了从行动到参考的递进关系。项目和领域是你当前关注的，资源和归档是为未来准备的。

## 四个层级

### P -- Projects（项目）

- **定义**：有明确目标和截止日期的短期努力
- **特征**：有终点、有交付物、有时间线
- **例子**：写一本书、发布一个产品、策划一次旅行、完成一个客户报告
- **判断标准**：能问"完成了吗？"的问题

### A -- Areas（领域）

- **定义**：需要持续维护的长期责任范围
- **特征**：无终点、有标准、需要持续关注
- **例子**：健康、财务、职业发展、家庭关系、房屋维护
- **判断标准**：能问"我维持标准了吗？"的问题

### R -- Resources（资源）

- **定义**：感兴趣的主题和参考材料
- **特征**：暂时没有具体用途，但未来可能有用
- **例子**：设计模式、认知科学笔记、烹饪技巧、演讲技巧
- **判断标准**：能问"我对这个话题感兴趣吗？"的问题

### A -- Archives（归档）

- **定义**：来自其他三个类别的不活跃内容
- **特征**：不再活跃但保留备用
- **例子**：已完成的项目、不再负责的领域、失去兴趣的资源
- **判断标准**：所有"不确定要不要保留"的东西都放这里

## PARA 的关键洞察

**所有信息都可以归入这四个类别** -- 听起来不可思议，但正是因为简单，它才有效。如果一个组织系统和你的生活一样复杂，维护它的精力就会夺走你真正生活所需的精力。

> 你的组织系统必须如此轻松，以至于它解放你的注意力，而不是限制它。系统必须为你提供时间，而不是消耗时间。 -- Tiago Forte

## 快速分类流程

遇到新信息时，依次问三个问题：
1. 这对哪个**项目**有用？
2. 如果没有，对哪个**领域**有用？
3. 如果没有，属于哪个**资源**？
4. 如果以上都不是，归档或不保存

## PARA 的流动性

PARA 的四个类别不是静态的：
- 项目完成后移入归档
- 归档中的内容可以被重新激活为新项目
- 资源可以升级为项目或领域
- 领域中的某个方面可能具体化为项目

## 与其他系统的对比

| 特征 | PARA | 传统文件夹 | 标签系统 |
|------|------|------------|----------|
| 分类依据 | 可行动性 | 主题/学科 | 关键词 |
| 灵活性 | 高（项目周期性流动） | 低（固定层级） | 中（可多标签） |
| 维护成本 | 低 | 高 | 中 |
| 面向目标 | 面向输出和行动 | 面向存储和检索 | 面向发现和归类 |
