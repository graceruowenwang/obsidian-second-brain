# CODE方法论

CODE 是 Tiago Forte 提出的构建和使用第二大脑的四步方法：**Capture（捕获）、Organize（组织）、Distill（提炼）、Express（表达）**。它不是一次性流程，而是持续循环的工作方式。

## C -- Capture（捕获）

把有价值的想法和洞见从信息源中提取出来，保存到一个集中的地方。

**核心原则：**
- **像策展人一样思考**：不要被动地消费信息，而是有意识地选择保存什么。用"稍后阅读"应用（如 Readwise Reader、Instapaper）替代即时消费
- **只保存引发共鸣的内容**：不要做高度分析性的决定，而是凭借直觉 -- 保存任何在深层面上与你产生"共鸣"的内容
- **利用捕获工具**：电子书导出高亮、网页剪藏、语音转文字、社交媒体收藏等

**关键心态转变：** 从"我需要记住这个"变成"我知道在哪里找到这个"。

## O -- Organize（组织）

将捕获的信息按**可行动性**而非主题来分类归档，使用 [[PARA系统]]。

**核心原则：**
- **按行动性组织**：问自己"这条信息对哪个项目有用？"而不是"这个属于什么主题？"
- **从空白开始**：不要试图整理所有旧笔记，而是将它们全部移入归档，从干净的状态重新开始
- **三个问题快速分类**：(1) 这对哪个项目有用？(2) 如果没有，对哪个领域有用？(3) 如果没有，属于哪个资源？

## D -- Distill（提炼）

将笔记逐层提炼为可操作的、精简的摘要。核心工具是 [[渐进式总结]]。

**核心原则：**
- **为未来的自己设计笔记**：把做笔记想象成时间旅行 -- 你在向未来的自己发送知识包裹
- **渐进式总结**：在多个阶段中逐步提炼，而不是一次性完美总结
- **机会主义地提炼**：每次接触笔记时增加一点价值，而不是一次性投入大量时间

## E -- Express（表达）

将积累的知识转化为具体的创造输出和行动。这是整个体系的最终目的。

**核心原则：**
- **主动输出，而非被动消费**：信息只有在被使用时才变成知识
- **创造更小的、可复用的工作单元**（Intermediate Packets）：每次工作结束时完成一个中间产物
- **分享你的作品**：不要等一切"准备好"，先发布 v1.0 版本，再迭代改进

## CODE 的循环本质

CODE 不是线性的流水线，而是持续的循环：
- Express 阶段会产生新的 Capture 需求
- Distill 过程中会发现新的 Organize 方式
- 整个过程在每一次知识工作中反复发生
