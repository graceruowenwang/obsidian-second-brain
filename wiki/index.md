# Wiki Index

## 概念体系

### 核心概念 -- 知识管理领域中最基础的观点和立场
- [[第二大脑]] -- 外部化的数字知识管理系统，将信息消费转化为创造输出
- [[个人知识管理]] -- 系统化地收集、组织、提炼和运用个人知识的实践方法
- [[知识网络]] -- 以节点和边构成的网状知识结构，区别于传统的树状分类

### 导航地图 -- 主题概览与阅读路径
- [[MOC-知识管理]] -- 知识管理领域的全景导航、阅读路径和角色推荐

### 方法框架 -- 用来分析和组织知识的结构化工具
- [[CODE方法论]] -- 构建第二大脑的四步方法：Capture、Organize、Distill、Express
- [[PARA系统]] -- 按可行动性递减组织数字信息的四层分类系统
- [[渐进式总结]] -- 在多个阶段逐步提炼笔记，使其在不同粒度下可快速理解
- [[卡片盒笔记法]] -- Luhmann 发展的原子化、密集链接的笔记网络方法
- [[常青笔记]] -- Andy Matuschak 提出的概念导向、持续演进的笔记实践
- [[中间包]] -- 将工作分解为更小的、可复用的产出单元
