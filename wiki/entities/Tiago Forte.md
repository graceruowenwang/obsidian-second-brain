**Tiago Forte** 是一位美国作家、知识管理专家，以其提出的 [[SecondBrain|第二大脑]] 方法论而闻名。他是《Building a Second Brain》（2022）一书的作者，该书将个人知识管理从学术概念推向大众实践。

## 核心贡献

Forte 的核心贡献在于提出了两套相互关联的知识管理框架：

### CODE 方法论

CODE 是第二大脑的核心操作流程，代表四个连续阶段：
- **Capture（捕获）**：有选择性地收集有价值的信息
- **Organize（组织）**：使用 [[PARA|PARA 系统]] 按可行动性分类
- **Distill（提炼）**：通过 [[ProgressiveSummarization|渐进式总结]] 技术逐层提炼要点
- **Express（表达）**：将知识用于创造新作品

### PARA 系统

PARA 是信息组织的四层架构，按行动性递减排列：
- **Projects（项目）**：有明确目标和截止日期的工作
- **Areas（领域）**：需要持续维护的责任范围
- **Resources（资源）**：感兴趣的主题和参考材料
- **Archives（归档）**：不再活跃但保留备用的内容

### 中间包与知识复利

Forte 提出了 [[IntermediatePackets|中间包]] 概念——任何"半成品"形态的知识片段（如一段话、一张幻灯片、一条引用）。这些模块化单元可在不同项目中复用，产生知识复利效应。

## 方法论渊源

Forte 的方法深受 [[Zettelkasten|卡片盒笔记法]] 的影响。CODE 中的 Capture 和 Distill 阶段直接借鉴了 Zettelkasten 的实践，但在行动性导向和工具适配方面做了现代化改造。与 [[EvergreenNotes|常青笔记]] 和 [[LinkingYourThinking|LYT 方法论]] 类似，Forte 强调知识之间的链接而非堆砌。

## 关键理念

- **"记住"不是目的，"找到"才是**：知识管理的核心不是记住所有信息，而是在需要时能快速找到并使用它
- **知识服务于行动**：信息的组织方式应反映其可行动性，而非学科归属
- **为自己而写**：笔记的读者是未来的自己，用未来自己能理解的方式写

## 影响力

Forte 的 CODE 和 PARA 框架已成为知识管理社区最广泛使用的实践方法之一。在 [[AiAssistedCoding|AI 辅助编程]] 和 [[LLMWiki|LLM Wiki 方案]] 兴起的时代，其"知识复用"理念与 [[RetrievalAugmentedGeneration|检索增强生成 (RAG)]] 等技术趋势相呼应。
