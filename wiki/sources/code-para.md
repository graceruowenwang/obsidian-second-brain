## 概述

Tiago Forte 提出的 **CODE 方法论** 和 **PARA 系统** 是构建 [[SecondBrain|第二大脑]] 的核心框架。CODE 定义了从信息捕获到知识创造的工作流，PARA 则提供了组织这些信息的分类架构。两者结合，旨在将知识从被动存储转变为主动创造的生产力引擎。

## CODE 方法论：知识工作流

CODE 代表四个连续阶段，强调知识的动态流动而非静态存储。

- **C - Capture（捕获）**：有选择性地从外部来源（文章、书籍、对话）收集信息。核心原则是只捕获“有共鸣”的内容，而非试图记录一切。
- **O - Organize（组织）**：使用 [[PARA|PARA 系统]] 将捕获的信息分类存储，使其可检索、可行动。
- **D - Distill（提炼）**：通过 [[ProgressiveSummarization|渐进式总结]] 技术，逐步提炼笔记精华。该技术将笔记分为四层：原始笔记、加粗、高亮和执行摘要，使核心信息“一眼可见”。
- **E - Express（表达）**：将组织好的知识用于创造新作品（文章、项目、决策）。核心理念是知识的价值在于被重新利用和组合，而非存储。

## PARA 系统：信息组织架构

PARA 是文件组织架构，用四个顶层文件夹管理所有数字信息，按行动性递减排列。

- **Projects（项目）**：有明确目标和截止日期的短期努力，如“完成Q2报告”。
- **Areas（领域）**：长期持续的责任区域，如“健康”、“财务”。
- **Resources（资源）**：持续感兴趣的主题或学习材料，如“设计思维”。
- **Archives（归档）**：以上三类中不再活跃的内容，储备但不丢弃。

PARA 的设计哲学强调**跨平台通用**和**可流动性**，信息可在四个类别间自由移动。例如，项目完成后归入 Archives，兴趣变成责任则从 Resources 升级到 Areas。

## 中间包（Intermediate Packets）

[[IntermediatePackets|中间包]] 是知识复用的核心概念，指任何“半成品”形态的知识片段（如一段话、一张幻灯片、一条引用）。它们具有模块化、可复用和灵活性的特性，使得“借用创意”成为可能，打破了“每次都从零开始”的低效模式，实现知识的复利效应。

## 关键要点

1.  **工作流与组织分离**：CODE 定义了“如何做”，PARA 定义了“如何放”，两者互补。
2.  **渐进式提炼**：通过 [[ProgressiveSummarization|渐进式总结]] 的四层结构，避免笔记成为信息垃圾场，确保核心价值可快速提取。
3.  **知识复利**：[[IntermediatePackets|中间包]] 是实现知识复利的关键，通过模块化复用，让旧知识持续产生新价值。
4.  **行动导向**：PARA 系统按行动性递减排列，确保最活跃的信息（项目）离用户最近，提升工作效率。
