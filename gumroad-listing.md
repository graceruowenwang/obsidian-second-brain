# Gumroad 产品页文案

## 产品名称

Second Brain — AI Knowledge Compiler for Obsidian

## 简短描述

Transform scattered notes into a structured, interlinked wiki — powered by AI. Free and open source.

---

## 完整描述

**Second Brain** is a free, open-source Obsidian plugin that compiles your raw notes, articles, and highlights into a structured, interconnected knowledge base — automatically.

**Second Brain（第二大脑）** 是一款免费开源的 Obsidian 插件，能将你的原始笔记、文章剪藏和高亮内容自动编译为结构化、相互链接的知识库。

### How it works / 工作原理

1. **Dump your materials** into `raw/` — articles, book notes, tweets, podcasts, flash cards
   **放入素材** — 把文章、读书笔记、推文、播客、闪念丢进 `raw/` 目录

2. **Hit Compile** — AI analyzes everything and generates a wiki with concepts, entities, sources, and cross-page links
   **一键编译** — AI 自动分析所有素材，生成包含概念、实体、来源和双向链接的 wiki

3. **Browse & Chat** — explore your wiki in the built-in browser, or ask questions with AI-powered search
   **浏览与对话** — 在内置浏览器中浏览 wiki，或通过 AI 语义搜索提问

### Features / 功能

- **AI Chat with your wiki** — ask questions, get answers grounded in your own knowledge base (with semantic search)
  **AI 对话** — 基于你自己的知识库提问和获得回答（支持语义向量搜索）

- **Auto Compile** — materials change? Wiki updates automatically in the background
  **自动编译** — 素材有变动？wiki 自动在后台增量更新

- **Knowledge Gap Detection** — finds broken links and generates stub pages for missing concepts
  **知识缺口检测** — 自动发现断链，为缺失概念生成占位页面

- **Smart Auto-Linking** — discovers semantic connections between pages using vector embeddings
  **智能补链** — 通过向量嵌入发现页面之间的语义关联，自动添加双向链接

- **Multi-provider LLM support** — DeepSeek, OpenAI, Anthropic, OpenRouter, or any OpenAI-compatible API
  **多模型支持** — DeepSeek、OpenAI、Anthropic、OpenRouter 及任何 OpenAI 兼容 API

- **Incremental compilation** — only re-processes changed files, saves tokens and time
  **增量编译** — 只处理变化的文件，节省 token 和时间

- **SVG Mind Map** — interactive visual knowledge graph
  **SVG 知识图谱** — 可交互的可视化知识网络

### Requirements / 系统要求

- Obsidian desktop (v1.8.7+) / Obsidian 桌面版 v1.8.7+
- An LLM API key (DeepSeek, OpenAI, Anthropic, etc.) / 一个 LLM API Key（DeepSeek、OpenAI、Anthropic 等）

### Install / 安装

1. Open Obsidian Settings -> Community Plugins -> Browse
   打开 Obsidian 设置 -> 第三方插件 -> 浏览

2. Search for "Second Brain", click Install, then Enable
   搜索 "Second Brain"，点击安装，然后启用

3. Configure your LLM API key in plugin settings, then compile
   在插件设置中配置 LLM API Key，然后开始编译
