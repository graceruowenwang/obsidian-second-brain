# Second Brain 宣传视频 -- 制作步骤指南

> 目标：6-7 分钟 B站视频，PPT 讲解 + Obsidian 录屏穿插
> 你需要准备的：Mac 电脑、麦克风、剪映（免费）

---

## 第一步：准备 Demo 数据（10 分钟）

Demo 素材已经在 `second-brain-release/demo/` 里准备好了，直接用。

### 操作前确认

1. 用 Obsidian 打开 `second-brain-release/` 这个 vault
2. 确认 API Key 已配好，点击测试连接通过
3. 确认 wiki/ 下的内容是完整的（有概念页、实体页、综合分析）
4. 点开 Wiki 浏览器，确认有卡片索引
5. 切到紫色暗色主题

## 第二步：导出 PPT 图片（5 分钟）

1. 打开 `SecondBrain-Bilibili.pptx`（用 PowerPoint 或 Keynote）
2. 导出为图片：
   - **Keynote**：文件 → 导出到 → 图像 → 所有幻灯片 → PNG
   - **PowerPoint**：文件 → 导出 → 更改文件类型 → PNG
3. 得到 16 张 PNG 图片，放到一个文件夹

---

## 第三步：写旁白脚本到手机/纸上（10 分钟）

把 `storyboard.md` 里的旁白部分单独整理出来，打印或放到手机上方便录音时看。

核心原则：**先录音，再录屏，最后剪辑**。这样你不用同时说话和操作。

---

## 第四步：录制旁白音频（30 分钟）

1. 打开 QuickTime：文件 → 新建音频录制
2. 按分镜脚本的顺序，逐段朗读旁白
3. **每段之间停顿 3 秒**，方便后期剪辑
4. 每一段单独录一个文件，命名如：`旁白-01-标题.mp3`、`旁白-02-痛点.mp3`...
5. 说错了就重录那段，不用从头来

## 第五步：录制 Obsidian 操作（30 分钟）

1. 打开 QuickTime：文件 → 新建屏幕录制
2. 选"录制选定部分"，框选 Obsidian 窗口
3. 关闭通知，关闭无关窗口

按以下顺序录制（每段单独录一个文件）：

### 录屏 A：安装+配置（对应旁白 10）
- 打开 GitHub Releases 页面
- 下载 zip 包（可以提前下载好，演示点击过程）
- 用 Obsidian 打开 vault
- 打开设置 → 填入 API Key → 点测试连接 → 显示成功
- 录完后保存为 `录屏-安装配置.mov`

### 录屏 B：编译过程（对应旁白 11）
- 打开 raw/ 目录，展示素材：
  - 01-articles/ 下的 5 篇文章
  - 02-podcasts/ 下的播客笔记
  - 06-flash_notes/ 下的闪念笔记
- 点击闪电图标 → 开始编译
- 展示编译日志滚动
- 编译完成
- 保存为 `录屏-编译.mov`

### 录屏 C：Wiki 浏览器（对应旁白 12+13）
- 点击左侧地球图标进入 Wiki
- 浏览卡片索引，展示分类：
  - 核心概念（第二大脑、个人知识管理、知识网络）
  - 方法框架（CODE方法论、PARA系统、渐进式总结、卡片盒笔记法等）
  - Entities（TiagoForte、NiklasLuhmann、AndyMatuschak）
  - Syntheses（方法论比较、RAG结合等）
- 点开 [[第二大脑]] 概念页，展示定义和关联连接
- 滚动到关联连接区域，展示双向链接
- 展示反向链接
- 回到文件夹，展开 wiki/ 目录树
- 保存为 `录屏-Wiki浏览.mov`

### 录屏 D：AI 对话（对应旁白 17）
- 打开对话面板
- 输入："知识管理的核心方法论有哪些？"
- 等待回答（可以提前问一次，演示时直接展示结果）
- 展示回答中的 [[wiki-links]] 引用（如 [[CODE方法论]]、[[卡片盒笔记法]]）
- 点击一个链接跳转到对应 Wiki 页面
- 保存为 `录屏-AI对话.mov`

### 录屏 E：自动编译（对应旁白 19）
- 展示自动编译开关
- 往 raw/ 丢一个新文件
- 展示自动触发编译
- 保存为 `录屏-自动编译.mov`

> 技巧：每段录屏可以录 2-3 遍，选最流畅的一条用。操作时不用说话，旁白是单独录的。

## 第六步：剪映合成（1-2 小时）

### 6.1 创建项目

1. 打开剪映，新建项目，选 16:9 横屏
2. 分辨率选 1080p 或 4K

### 6.2 导入素材

把所有旁白音频、PPT 图片、录屏视频导入剪映素材库

### 6.3 按分镜脚本拼接

按照以下顺序，逐段往时间线上放：

| 顺序 | 画面素材 | 旁白音频 | 说明 |

| 02 | PPT图3-痛点 | 旁白02 | 图片停留25秒 |
| 03 | PPT图4-方案 | 旁白03 | 图片停留15秒 |
| 04 | PPT图5-Karpathy | 旁白04+05 | 图片停留25秒 |

### 6.4 对齐画面和声音

- PPT 图片段：调整图片时长 = 旁白音频时长
- 录屏段：把旁白音频和录屏对齐，录屏中等待的部分用 2x 加速
- 段与段之间加 0.5 秒交叉溶解转场

### 6.5 加字幕

1. 选中时间线所有音频
2. 点击"智能字幕" → "识别字幕"
3. 等待识别完成
4. 手动校对：Obsidian、DeepSeek、Wiki、API Key 等专有名词
5. 字幕样式选白色文字+半透明黑底，放在画面底部

### 6.6 加背景音乐（可选）

1. 剪映素材库搜 Lo-fi 或轻音乐
2. 拖到音频轨道
3. 音量调到 10-15%（不要盖过旁白）

### 6.7 导出

1. 点击右上角导出
2. 选 1080p 或 4K
3. 格式 MP4
4. 导出完成
