常见问题

API 费用大概是多少？
推荐 DeepSeek API，约 1 元/百万 token。首次全量编译消耗最多，增量编译只处理变化的文件。日常使用（每月几十条笔记），充值 10 元可用几个月。你的 API Key 仅保存在本地。
支持哪些 LLM？
DeepSeek、OpenAI、Claude、OpenRouter，以及任何 OpenAI 兼容 API。可以在设置中自由切换。
我的数据安全吗？
完全安全。所有笔记数据都在你的 Obsidian Vault 本地。API Key 仅保存在本地配置中，不会上传到任何服务器。唯一的外部通信是调用你选择的 LLM API 进行编译和对话。
License 是永久的吗？
是的，30 元一次买断，永久使用。不订阅，不续费。绑定单台设备，如需更换设备可在设置中先停用再重新激活。
