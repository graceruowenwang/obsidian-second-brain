从安装免费版到现在，我每天的笔记效率直接翻了一倍。今天，我正式开放 **完整版**，把最硬核的功能打包给大家。

### 我为什么要做这个插件？

用 Obsidian 写笔记越久，越发现一个问题：

笔记写了上百篇，但**找不到、连不上、用不起来**。

读书笔记、文章剪藏、播客心得、闪念碎片......全都躺在文件夹里吃灰。偶尔想找某个知识点，全局搜索出一堆零散结果，还要自己人工拼凑上下文。

我试过手动建 MOC、用 Dataview 做索引、甚至手写双链关系。有效，但**太累了**，坚持不下来。

所以我做了 Second Brain —— 让 AI 替你完成从碎片到结构这步最枯燥的工作。

---

### 它是怎么工作的？

三步：

**第一步：放入素材**

文章、读书笔记、播客笔记、闪念笔记，丢到 `raw/` 目录下就行。支持 Markdown 和纯文本，也支持自动检测 Vault 里已有的笔记导入。

**第二步：AI 编译**

点击编译，LLM 自动提取概念、实体和知识来源，生成带 `[[双向链接]]` 的结构化 Wiki 页面。

重点：**支持增量编译**。只有变化的文件才重新处理，后续编译几秒完成，不浪费 token。

**第三步：浏览与对话**

编译完成后，你得到的不只是一堆文件，而是一个**真正可浏览的知识库**：

- 卡片式 Wiki 索引，按概念、实体、素材分类
- 语义搜索（基于向量 Embedding，不只是关键词匹配）
- 每个页面自动关联相关概念，不会产生孤岛

### 为什么免费版就值得一试？

即使不付费，你也能立刻用上核心功能：

- **手动编译**：全量或单文件，按需编译
- **Wiki 浏览器**：卡片索引、页面阅读器、反向链接
- **多 LLM 支持**：DeepSeek、OpenAI、Claude、OpenRouter，以及任何 OpenAI 兼容 API
- **多语言界面**：中文、英文、日文
- **向量语义搜索**：基于 Embedding 的语义搜索，带关键词回退
- **笔记库扫描**：自动检测已有笔记并导入为素材

很多用户安装后第一天就说：「光免费版的编译功能就值了。」

---

### 完整版到底强在哪里？

完整版在免费版基础上，解锁了进阶玩家最想要的功能：

- **自动编译**：监听 `raw/` 目录变化，有新素材自动编译，不用手动点。早上扔进去一篇文章，喝杯咖啡回来，知识库已经更新好了。

- **AI 对话**：和你的知识库直接对话。提问后，AI 会从你编译过的知识中找答案，并且用 `[[wiki-links]]` 标注引用来源。相当于你有了一个「读过你所有笔记」的研究助手。

- **SVG 知识图谱**：把你的概念网络可视化，交互式 SVG，一眼看清知识之间的关联。

- **一键切换 LLM**：不同任务用不同模型，一键切换后端，不用重新配置。

简单来说：**免费版让你「够用」**，**完整版让你「不用管」**。

- DeepSeek API 价格：输入约 1 元/百万 token，输出约 1.4 元/百万 token

你的 API Key 仅保存在本地 Obsidian 配置中，**不会上传到任何服务器**。
