# 你的笔记值得更好的归宿 -- 一款 AI 驱动的 Obsidian 知识编译器

> 你有没有过这样的经历：收藏了几百篇文章、记了几十条读书笔记，但真到用的时候，什么都找不到？

我们每天都在消费信息 -- 文章、播客、课程、会议记录。它们散落在各个文件夹里，彼此孤立，和"知识"两个字差了十万八千里。

**Second Brain** 是一个 Obsidian 插件，做一件事：**把你散乱的笔记自动整理成结构化、双向链接的知识库。**

不需要手动分类、不需要逐篇建链、不需要学习复杂的方法论。放进去，点一下编译，它帮你搞定。

## 它是怎么工作的

整个流程只有四步：

```
添加素材 → 一键编译 → 浏览 Wiki → 发现缺口 → 补充素材 → 再次编译
```

### 第一步：把笔记放进来

你的读书笔记、文章剪藏、播客心得、闪念碎片 -- 任何 Markdown 文件，放进 `raw/` 目录就行。

[截图占位：raw/ 目录结构，展示不同分类文件夹]

插件建议你放进来的应该是**已经理解、正在使用的知识**，而不是"收藏了但没看过"的内容。这不是收藏夹，是第二大脑。

### 第二步：点一下编译

点击右侧栏的编译图标（或 `Cmd/Ctrl + Shift + X`），选择"开始编译"。

[截图占位：编译面板，展示编译按钮和进度状态]

AI 会逐篇分析你的素材，自动提取：
- **概念** -- 核心观点、方法论、实践经验
- **实体** -- 人物、公司、工具
- **来源** -- 每篇素材的摘要

然后把它们组织成带有 `[[双向链接]]` 的 Wiki 页面。

[截图占位：编译结果报告，展示提取的概念、实体数量和变更统计]

### 第三步：浏览你的知识库

编译完成后，点击左侧栏的 Wiki 图标，进入 Wiki 浏览器。

[截图占位：Wiki 浏览器主界面，展示分类浏览]

你可以：
- 按**概念、实体、来源**分类浏览
- 用**关键词或语义搜索**快速找到内容
- 点进每个页面，查看完整内容和反向链接

[截图占位：Wiki 页面详情，展示双向链接和内容]

### 第四步：发现缺口，持续完善

Wiki 不只是一次性生成的静态页面。它会告诉你哪里还不够：

[截图占位：质量总览面板，展示知识缺口和待审核页面]

- **知识缺口检测** -- 自动发现断链，生成待补充页面
- **状态筛选** -- 一键筛选待审核、缺口页面
- **重新编译** -- 补充素材后再编译，知识库持续成长

## 两个让人"w"的功能

### AI 对话：直接问你的知识库

[截图占位：AI 对话界面，展示带有 wiki-link 引用的回答]

不用翻笔记了。直接用自然语言提问，AI 会从你的知识库中找到相关内容，回答里自带 `[[wiki-link]]` 引用来源，点击就能跳转。

你说的是"知识"，不是"搜索关键词"。

### 知识图谱：看见知识的形状

[截图占位：SVG 知识图谱，展示概念间的网络关系]

用可视化图谱看到概念之间的连接关系。哪些概念是枢纽，哪些是孤岛，一目了然。

## 不挑 AI，不贵

插件支持多个 LLM 后端，推荐用 DeepSeek：

| 后端 | 说明 |
|------|------|
| DeepSeek（推荐） | 注册送额度，月费几块钱 |
| OpenAI | GPT 系列 |
| Claude | Anthropic 模型 |
| OpenRouter | 多模型聚合 |
| 自定义 | 任何 OpenAI 兼容 API |

以 DeepSeek 为例，每月几十条笔记的使用量，充值 10 元用几个月。API Key 只保存在本地，不会上传。

## 界面支持中英日三语

插件界面支持中文、英文、日文切换。编译输出的知识库内容则跟随你的素材语言，不做强制翻译。

## 怎么开始

1. 下载项目文件，解压后用 Obsidian 打开（作为库）
2. 启用插件，按向导配置 API Key（4 步完成）
3. 点编译，看结果

从放素材到看到知识库，第一次只需要 5 分钟。
