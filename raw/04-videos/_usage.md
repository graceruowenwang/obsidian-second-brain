# 04-videos

视频内容笔记、演讲摘要、教程要点。

## 放什么

- YouTube 视频笔记
- 会议演讲、TED 演讲整理
- 在线课程笔记

## 格式要求

- Markdown 格式（.md）
- 建议标注视频标题、链接、作者
- 可以是时间戳笔记或主题摘要

## 示例

```markdown
# 视频：Andrej Karpathy -- Let's build GPT

链接: https://youtube.com/watch?v=xxx
作者: Andrej Karpathy
日期: 2026-02-20

## 要点

- Tokenizer 的工作原理...
- Transformer 架构的核心是注意力机制...
```
