## Cursor

**定位**：AI 原生的代码编辑器（基于 VS Code fork）

核心功能：
- Tab 补全、内联编辑、多文件编辑（Composer）
- 支持多种模型（Claude、GPT-4 等）
- `.cursorrules` 文件用于项目级自定义规则
- Agent 模式：可自动读取文件、运行命令、执行多步骤操作

优势：深度 IDE 集成，最接近"AI 编辑器"的概念
劣势：需要从 VS Code 迁移，大型项目上下文窗口有限制

## Claude Code

**定位**：Anthropic 官方 CLI 编程代理

核心功能：
- 终端原生，直接在项目目录中工作
- 可以读取文件、运行测试、多步骤修复问题
- 支持 MCP (Model Context Protocol) 扩展
- `CLAUDE.md` 文件用于定制行为
- Anthropic 内部约 90% 的 Claude Code 代码由 Claude Code 自己编写

优势：对整个项目目录有完整上下文访问，适合复杂的多文件操作
劣势：命令行界面，学习曲线较陡

## GitHub Copilot

**定位**：集成在 IDE 中的 AI 结对编程工具

核心功能：
- 内联代码建议、聊天模式
- Agent 模式（2025 年推出）：可以异步克隆仓库、处理任务、打开 PR
- 自定义指令功能
- 与 GitHub 生态系统深度集成

优势：最广泛采用的 AI 编程工具，IDE 兼容性好（VS Code、JetBrains 等）
劣势：复杂的多文件编辑能力相对有限

## Windsurf（原 Codeium）

**定位**：首个 AI 原生 IDE，强调"流状态"开发体验

核心功能：
- Cascade：多步骤代码编辑代理，具备图谱驱动推理
- Supercomplete：智能代码补全
- 多文件连贯编辑
- 一键部署到公网
- Smart Commit：自动生成提交信息

优势：免费额度较慷慨，多文件编辑能力强
劣势：用户基数相对较小，社区生态不如 Cursor

## 行业趋势（Pragmatic Engineer 2026 年调查）

900+ 受访者调查数据：
- 公司通常为工程师支付 $100-200/月的 AI 工具费用
- 约 30% 的受访者表示曾经触及使用上限
- 欧洲公司比美国公司更关注预算控制
- 多数受访者认为 AI 工具的当前定价模式"不可持续"
- 开发者会在触及 Cursor 月度限制时切换到 Windsurf，反之亦然
