# 03-podcasts

播客笔记、访谈摘要、音频内容整理。

## 放什么

- 播客节目笔记（手动记录或 AI 转写）
- 访谈要点整理
- 课程音频的笔记

## 格式要求

- Markdown 格式（.md）
- 建议标注节目名称、集数、嘉宾
- 可以是完整笔记，也可以是关键要点列表

## 示例

```markdown
# 播客：How I Built This -- Notion 创始人访谈

节目: How I Built This
嘉宾: Ivan Zhao (Notion CEO)
日期: 2026-03-15

## 要点

- Notion 最初是一个失败的项目...
- 关于 all-in-one 工具的设计哲学...
```
