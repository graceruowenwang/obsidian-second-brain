# 06-flash_notes

闪念笔记、原创思考、灵感记录。

## 放什么

- 随时记录的灵感和想法
- 读书或工作时的即兴思考
- 对某个话题的个人观点

## 格式要求

- Markdown 格式（.md）
- 不要求结构化，碎片化内容也可以
- 这里是你自己的原创思考，在编译时会被标注为 `[原创]`，优先级高于外部素材

## inbox 子目录

`inbox/` 是暂存区。随手记录的笔记可以先扔进去，编译时会自动根据内容重命名并移到 `06-flash_notes/` 正式目录。

## 示例

```markdown
# 关于学习的思考

今天读到一个观点说费曼学习法的核心不是"教别人"，而是"发现自己哪里不懂"。
这让我想到，很多时候我以为自己理解了一个概念，但写下来的时候才发现逻辑有断层。

也许写作本身就是一种检验理解的方式。
```
