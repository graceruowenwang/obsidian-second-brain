# 05-tweets

推文线程、社交媒体长文、短内容合集。

## 放什么

- Twitter/X 推文线程（thread）
- 微博长文
- 其他社交媒体上的有价值短内容

## 格式要求

- Markdown 格式（.md）
- 一个文件对应一个线程或主题
- 建议标注作者和原始链接

## 示例

```markdown
# 推文线程：关于知识管理的思考

作者: @someone
日期: 2026-04-10

1/ 知识管理最核心的问题不是工具，而是你如何思考...

2/ 第二大脑不是把所有东西存下来，而是建立概念之间的连接...

3/ 写作是最好的思考工具，因为它迫使你把模糊的想法变成清晰的表述...
```
