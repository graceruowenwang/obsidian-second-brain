# 如何构建你的第二大脑

来源: https://example.com/building-second-brain
日期: 2026-04-15

## 核心观点

第二大脑（Second Brain）是一个外部化的知识管理系统。它的目标不是记住所有信息，而是把你接触到的信息组织成一个可以在需要时检索和组合的系统。

## CODE 方法论

Tiago Forte 提出的四个步骤：

1. **Capture（捕获）** -- 把有价值的信息从信息源中提取出来
2. **Organize（组织）** -- 按可行动性而非主题来组织信息
3. **Distill（提炼）** -- 逐层提炼，从粗到细标注要点
4. **Express（表达）** -- 用你自己的方式输出和分享

## PARA 系统

信息组织的四个层级：

- **Projects（项目）** -- 有明确目标和截止日期的工作
- **Areas（领域）** -- 需要持续维护的责任范围
- **Resources（资源）** -- 感兴趣的主题和参考材料
- **Archives（归档）** -- 不再活跃但保留备用的内容

关键洞察：PARA 的排序反映了从行动到参考的递进关系。项目和领域是你当前关注的，资源和归档是为未来准备的。

## 为什么传统笔记系统失败了

大多数人做笔记的问题不是工具不好，而是没有建立信息之间的连接。散落的笔记就像没有索引的图书馆 -- 信息都在，但找不到。

真正的知识管理是建立概念之间的网络，而不是堆砌文件。
