## CODE -- 四步核心工作流

CODE 是 BASB 的核心操作框架，代表四个连续阶段：

### C -- Capture（捕获）

从各种来源（文章、书籍、对话、播客）中有选择性地收集信息。核心原则是"捕获有共鸣的内容"，而非试图记录一切。

关键问题：这条信息是否引起了我的共鸣？它是否改变了我的想法？

### O -- Organize（组织）

使用 PARA 系统将捕获的信息分类存储，使其可检索、可行动。

### D -- Distill（提炼）

通过渐进式总结（Progressive Summarization）技术，逐步提炼笔记中的精华，使其"一眼可见"。

渐进式总结的四层结构：
- **第 1 层 -- 原始笔记**：完整捕获源材料的要点（约 100% 内容）
- **第 2 层 -- 加粗**：对第 1 层中约 20% 最重要的内容加粗
- **第 3 层 -- 高亮**：对加粗内容中约 25%（即原文的约 5%）进行高亮标注
- **第 4 层 -- 执行摘要**：在最关键的部分用一两句话写出核心要点

关键原则：不是所有笔记都需要处理到第 4 层，根据重要性灵活处理。

### E -- Express（表达）

将组织好的知识用于创造新作品（文章、演示、项目、决策）。知识不被"消费"，而是被"使用"。

核心理念：**知识的价值不在于存储，而在于被重新利用和组合。**

## PARA 组织系统

PARA 是文件组织架构，用四个顶层文件夹管理所有数字信息：

| 类别 | 定义 | 特征 | 举例 |
|------|------|------|------|
| **Projects（项目）** | 有明确目标和截止日期的短期努力 | 可完成、有终点 | "完成Q2报告"、"策划产品发布会" |
| **Areas（领域）** | 长期持续的责任区域 | 无截止日期、需持续维护 | "健康"、"财务"、"职业发展" |
| **Resources（资源）** | 持续感兴趣的主题或学习材料 | 参考性质、按兴趣组织 | "设计思维"、"心理学"、"摄影" |
| **Archives（归档）** | 以上三类中不再活跃的内容 | 储备但不丢弃 | 已完成的项目、过去的兴趣 |

### PARA 的核心设计哲学

- **按行动性递减排列**：Projects 最具行动性（离你最近），Archives 行动性最低（离你最远）
- **跨平台通用**：同一结构可应用于所有工具（云盘、笔记应用、邮件）
- **可流动性**：一条信息可以在四个类别之间自由移动。项目完成后归入 Archives，兴趣变成责任则从 Resources 升级到 Areas

## 中间包（Intermediate Packets）

知识复用的核心概念。中间包是任何"半成品"形态的知识片段 -- 一段话、一张幻灯片、一个图表、一条引用、一份清单。它们是大型作品的构建块。

核心特性：
- **模块化**：每个包是自包含的独立单元
- **可复用**：可在不同项目中直接插入使用，只需微调
- **灵活性**：可以按不同顺序和组合方式编排

与知识复利的关系：知识像金融资本一样可以产生复利效应。中间包使得"借用创意"成为可能 -- 从旧作品中提取片段重组到新作品，打破了"每次都从零开始"的低效模式。
